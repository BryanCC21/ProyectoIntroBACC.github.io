Configuración de una Red LAN para interconectar tres computadoras mediante un Switch,
configurar direcciones IP estáticas y habilitar el intercambio de archivos


Detalles del proyecto

Se interconectaron tres computadoras mediante un Switch con IPs estáticas en el rango 192.168.1.x, se verificó la comunicación con pings en CMD y se configuró una carpeta compartida en red con permisos de lectura y escritura para todos los integrantes
