Creacion de planos y funcionamiento de una
Red LAN en Packet Tracer


🌐 Detalles del proyecto

En este proyecto se realizo la creacion de planos y funcionamiento de una Red LAN en Packet Tracer, se configuro una Red LAN para que todas las computadoras puedan comunicarse mediante un Switches y dispositivos Wireless, se configuraron direcciones IP estáticas y se mandaron paquetes entre las computadoras, impresoras, tablets y laptops
